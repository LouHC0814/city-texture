# 经典建筑 3D 展台

打开城市纹理后，点页面中的 **经典建筑 3D**。第一份模型是 SDC 制作的埃菲尔铁塔，含完整的 147,604 个三角面与钢架细节。模型随发行文件保存，观看无需联网或账号。

## 旋转、缩放与观察角度

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 旋转 | 鼠标左键拖动模型画布 | 单指在画布内拖动 |
| 拉近 / 拉远 | 滚轮，或 ＋ / − 按钮 | 双指放大、捏合，或 ＋ / − 按钮 |
| 平移 | 鼠标右键拖动 | 双指一起移动 |
| 恢复构图 | 点“重置视角” | 点“重置视角” |
| 固定角度 | “立体视角”“正面”“俯视” | 同左 |

Tab 聚焦三维画布后，可用方向键转动、＋／− 缩放、Home 重置视角、空格切换自动旋转。默认不自动旋转；操作画布会暂停旋转。“线框”可观察网格结构。

“保存三维观察卡”下载带作者与许可的 1600 × 1200 PNG；“下载模型 GLB”保存自包含模型，文件本身保留来源和许可，方便在兼容工具中继续查看。

## 模型的精细程度与范围

这是一份第三方制作的建筑模型，保留钢架、塔脚与平台等细节，不是现场扫描或测绘成果，不用于量取现实尺寸。展示会统一居中和缩放。未提供室内漫游、真实街景、夜间灯光还原或建筑结构工程分析。

这一版只有埃菲尔铁塔一份独立三维模型。南京中山陵、中华门、紫峰大厦等精细模型尚未接入；南京新街口的 OSM 建筑轮廓仍在“城区比较”中使用，二者不是同一种数据。比较项目 JSON 保存的是城区比较，不包含三维相机或模型修改状态。

## 浏览器与失败恢复

建议用新版 Chrome 或 Edge，浏览器需支持 WebGL 2 和离线 gzip 解压。手机在画布外滑动可滚动页面，画布内用于模型操作。如果浏览器未启用图形渲染或上下文中断，程序会说明失败并提供重试入口；仍可回到城区比较。

隐藏三维模式或切换到后台时停止绘制。返回后恢复显示；没有伪装成三维模型的静态图片替代。自动化检查使用真实 Chrome 与软件 WebGL，覆盖鼠标、键盘、手机触摸、双指缩放、图形故障恢复及断网单文件；这不代表已经测试所有手机 GPU。
