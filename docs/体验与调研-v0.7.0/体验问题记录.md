## 问题 1｜打开比较：读不到文件时显示浏览器英文原始报错

- **复现步骤**：点"打开比较"→ 在选择文件对话框中指向一个当时不可读取的路径（文件在预览前被移走或删除即可触发）→ 面板出现红色错误。
- **预期**：中文提示，说明"文件读不到，请重新选择"，并保留面板让用户重选。
- **实际**：显示 `A requested file or directory could not be found at the time an operation was processed.`——浏览器抛出的英文原文，"打开这份比较"按钮保持禁用，没有任何中文解释。
- **影响**：低。程序行为安全（当前比较未被破坏、可重新选择），但中文界面里突然跳出英文技术消息，新手容易判断成"程序坏了"。
- **截图**：[打开比较的英文错误提示截图](04-打开比较-英文错误提示.png)

## 问题 2｜三维控制条在常见笔记本视口下落在首屏之外

- **复现步骤**：1440 × 960 视口打开程序 → 点"经典建筑 3D"→ 等待模型加载完成。
- **预期**：模型和"立体视角 / 正面 / 俯视 / ＋ − / 重置视角"这些控件在同一屏内看得到。
- **实际**：模型画布可见，但控制条在约 y = 1050 处，**首屏看不到**，必须再向下滚一屏才发现有视角按钮。我第一轮操作就因为控件在视口外，误以为"视角切换没反应"。
- **影响**：中低。功能正常，属于发现性问题；第一次用的人很可能只拖两下模型就退出，不知道还能一键换正面和俯视。
- **建议**：把控制条固定在画布下沿，或进入三维模式时让画布高度自适应剩余视口。
- **截图**：[三维展台首屏截图](05-三维展台-立体视角.png)（可见画布已展开、控制条不在画面内）
