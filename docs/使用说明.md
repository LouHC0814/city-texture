# 城市纹理 v0.7.0 使用说明

## 下载与打开

从 [最新发行版](https://github.com/LouHC0814/city-texture/releases/latest) 页面下方的 **Assets** 下载：

1. **推荐：city-texture-v0.7.0-offline.zip**。完整解压，打开文件夹，双击 **打开城市纹理.html**。
2. 也可以只下载 **city-texture-v0.7.0.html**，用 Chrome 或 Edge 打开。

使用时不需要安装 Node.js、Python，也不需要注册账号或联网取地图。推荐在电脑浏览器中体验；本版不是 EXE 安装程序。

如果 HTML 被文本编辑器打开，右键文件，选择“打开方式 → Google Chrome / Microsoft Edge”。不要在尚未解压的 ZIP 预览窗口内运行。

## 怎样看三维经典建筑

点页面中的“经典建筑 3D”，等待模型准备完成。第一份是有钢架细节的埃菲尔铁塔，可鼠标拖动或手机单指旋转，用滚轮、双指或 ＋／− 按钮缩放。正面、俯视和立体视角可一键切换，支持自动旋转、线框、三维观察卡和 GLB 下载。

模型与引擎随程序保存，断网可用；需要新版 Chrome / Edge 支持 WebGL 2。失败时可重试或回到城区比较。当前只有一份独立三维模型，南京精细模型尚未接入；不是扫描/测绘成果，不能量取真实尺寸。详见随包《三维建筑使用说明.md》《模型许可.md》。

## 可以做什么

- 从南京新街口、苏黎世老城、伯尔尼老城三个真实城区中任取两个，比较道路与建筑轮廓；在城市列表中选择“南京”即可。
- 切换 250 米、500 米、750 米、1 公里的统一观察范围。
- 切换“道路”“道路＋建筑”“建筑”图层。
- 拖动任意地图，两侧连动；也可使用方向按钮，或聚焦地图后按键盘方向键。
- 点“居中”回到样本中心；点“重置”恢复默认城市、尺度与图层。
- 保存 PNG 观察卡、下载 JSON 报告，或复制视图参数给拥有同版本文件的朋友恢复。
- 点“管理样本”，离线导入其他城区的城市纹理样本包；最多同时导入 3 份。

## 保存比较，下次接着看

1. 点“保存比较”，下载 `城市纹理-比较项目.json`。文件会带上当前城市、尺度、筛选、图层、位置，以及全部导入样本。
2. 下次打开程序，点“打开比较”，选择这个文件；查看预览后点“打开这份比较”。手机和断网也可使用。
3. 选择文件或关闭预览不改变当前比较；点击打开后会替换当前导入集合和位置。需要保留当前工作时，请先关闭面板并保存。
4. 文件最多 32 MiB，最多包含三份导入样本。使用保存时的程序版本最稳妥；内置数据版本不一致会提示并保留当前工作。离线 ZIP 附《比较项目格式与恢复.md》。

## 怎样导入其他城区

1. 点“管理样本”，选择样本包 JSON，再点“加入左侧比较”。成功后关闭面板即可观察。
2. 当前支持城市纹理样本包 v1，最多 8 MiB。可下载内置样本包查看格式；统计报告、GeoJSON 和原始 Overpass 文件需先转换。离线 ZIP 内附《样本包格式与导入.md》，源码中同样可在 `docs/` 中找到。
3. 样本只在当前页面保留，刷新或关闭后可打开已保存的比较项目，也可重新导入。面板可下载完整样本包、移除导入样本；移除正在显示的样本时，相应地图回到内置样本。
4. 数据只在浏览器处理。导入数据的来源、许可、查询与哈希为提供者声明，应用没有重新下载原始数据核验，不把它当成项目核验的内置快照。

样本包需同时包含道路、建筑和独立来源记录；两份下载框都应完整覆盖所有预设观察尺度。空的建筑数组表示提供者声明此样本没有收录建筑，不能据此推断当地没有建筑。

## 怎样分享视图

点“复制当前比较”，将生成的参数发给朋友。朋友使用支持相同样本的版本后，点“恢复视图”并粘贴即可。若包含导入的城区，可直接分享通过“保存比较”下载的完整项目；也可把样本包一同发给朋友，请对方先导入，再恢复参数。JSON 统计报告不能替代样本包或比较项目。

复制失败时会出现手动复制框。此功能不会把本地文件变成公开网站；本版没有在线部署。

## 数据与范围

当前内置三个局部城区样本。南京道路和建筑分别抓取于 2026-10-17 UTC；瑞士道路抓取于 2026-10-15 UTC，建筑抓取于 2026-10-16 UTC。样本范围、数据完整度和抓取时间都会影响结果。

南京新街口样本包含地下及室内通道，勾选步行道路时参与统计；地图为二维平面，没有区分层级，不能将所有线条都理解为地面街道。

建筑数字是 OSM 轮廓要素数，不是实际楼栋或住房数。方向多样性用于描述路网形态，不评判城市好坏。

地图数据 © OpenStreetMap contributors，采用 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。代码采用 MIT。地图署名和许可信息保留在应用与导出中。

## 发行文件说明

- HTML：包含全部地图数据、样式和代码，可独立打开。
- 离线 ZIP：包含同一份 HTML、说明、三维建筑使用指南、比较项目与样本包格式、程序/数据/模型/引擎许可及版本信息。
- 版本信息 JSON：记录版本与对应源码提交，普通使用无需操作。
- 校验值 TXT：供需要核对下载完整性的人使用，普通使用无需操作。
- GitHub 自动提供的 Source code ZIP / tar.gz：供开发者获取源码；直接体验请选择上面的 HTML 或离线包。
