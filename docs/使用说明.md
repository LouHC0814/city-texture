# 城市纹理 v0.3.0 使用说明

## 下载与打开

从 [最新发行版](https://github.com/LouHC0814/city-texture/releases/latest) 页面下方的 **Assets** 下载：

1. **推荐：城市纹理-v0.3.0-离线包.zip**。完整解压，打开文件夹，双击 **打开城市纹理.html**。
2. 也可以只下载 **城市纹理-v0.3.0.html**，用 Chrome 或 Edge 打开。

使用时不需要安装 Node.js、Python，也不需要注册账号或联网取地图。推荐在电脑浏览器中体验；本版不是 EXE 安装程序。

如果 HTML 被文本编辑器打开，右键文件，选择“打开方式 → Google Chrome / Microsoft Edge”。不要在尚未解压的 ZIP 预览窗口内运行。

## 可以做什么

- 比较苏黎世、伯尔尼两片真实城区的道路与建筑轮廓。
- 切换 250 米、500 米、750 米、1 公里的统一观察范围。
- 切换“道路”“道路＋建筑”“建筑”图层。
- 拖动任意地图，两侧连动；也可使用方向按钮，或聚焦地图后按键盘方向键。
- 点“居中”回到样本中心；点“重置”恢复默认城市、尺度与图层。
- 保存 PNG 观察卡、下载 JSON 报告，或复制视图参数给拥有同版本文件的朋友恢复。

## 怎样分享视图

点“复制当前比较”，将生成的参数发给朋友。朋友下载本发行版后，点“恢复视图”并粘贴即可。

复制失败时会出现手动复制框。此功能不会把本地文件变成公开网站；本版没有在线部署。

## 数据与范围

当前仅内置两个城区样本，不是全球城市搜索。道路抓取于 2026-10-15 UTC，建筑抓取于 2026-10-16 UTC。样本范围、数据完整度和抓取时间都会影响结果。

建筑数字是 OSM 轮廓要素数，不是实际楼栋或住房数。方向多样性用于描述路网形态，不评判城市好坏。

地图数据 © OpenStreetMap contributors，采用 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。代码采用 MIT。地图署名和许可信息保留在应用与导出中。

## 发行文件说明

- HTML：包含全部地图数据、样式和代码，可独立打开。
- 离线 ZIP：包含同一份 HTML、说明、程序/数据许可及版本信息。
- 版本信息 JSON：记录版本与对应源码提交，普通使用无需操作。
- 校验值 TXT：供需要核对下载完整性的人使用，普通使用无需操作。
- GitHub 自动提供的 Source code ZIP / tar.gz：供开发者获取源码；直接体验请选择上面的 HTML 或离线包。
