# 参考与致谢

本项目为独立编写的城市形态观察原型。以下是方法或视觉层次参考，不是运行时依赖；没有复制它们的业务代码、图片、地图预设或生成结果。

| 来源 | 参考的思路 | 本项目中的实现 |
| --- | --- | --- |
| [anvaka/city-roads](https://github.com/anvaka/city-roads) | 以道路为主要视觉元素，公开数据缓存减少等待 | 自己编写 Canvas 绘图、双城对照与本地样本加载 |
| [marceloprates/prettymaps](https://github.com/marceloprates/prettymaps) | 地图的视觉层次和克制的配色 | 自己设计纸色界面与道路分层；未使用源码、配色预设或图片 |
| [gboeing/osmnx](https://github.com/gboeing/osmnx) | 路网方向、长度加权与方向熵的分析方法 | 自己实现局部投影、线段裁剪、无向去重与固定分箱统计，公开与原库流程的差异 |
| [pysal/momepy](https://github.com/pysal/momepy) | 将城市形态转为可解释指标 | 选择少量可核验指标，避免综合优劣排名 |
| [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) | 调研过的通用地图引擎候选 | 当前未引入，原型不依赖在线矢量瓦片 |

地图数据直接从 [Swiss Overpass API](https://overpass.osm.ch/) 获取，归属于 OpenStreetMap contributors，遵循 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。代码许可与数据许可分开，详见 [数据许可](../数据许可.md)。

方向熵是已有的统计方法，本项目不主张发明。中文交互、同尺度比较、观察卡与报告的产品组合及程序实现属于本项目的具体工作。

浏览器验证脚手架沿用作者已有的个人项目检查方式，并根据本项目的地图与数据行为调整；运行时没有第三方库。
