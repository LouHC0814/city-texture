这是「城市纹理」首个提供成品下载的发行版。

## 下载后怎么用

在下方 **Assets** 下载 **city-texture-v0.3.0-offline.zip**，完整解压后双击 **打开城市纹理.html**。

也可直接下载 **city-texture-v0.3.0.html**，用 Chrome / Edge 打开。两种方式都不需要安装 Node.js、Python 或其他依赖，断网也能运行。

## 本版功能

- 苏黎世、伯尔尼两份真实城区的同尺度路网与建筑观察。
- 四种观察尺度、三种显示图层；建筑内院保留为空白。
- 鼠标、触摸、键盘连动平移，以及下载范围边界限制。
- 道路长度、密度、方向分布与建筑轮廓要素计数。
- PNG 观察卡、JSON 数据报告，以及可复制恢复的观察视图。

当前是两个局部城区样本，没有全球搜索或在线部署；建筑轮廓数不等于实际楼栋数。
