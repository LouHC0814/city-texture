这一版让城市纹理支持离线加入其他城区的样本包。

## 下载后怎么用

在下方 **Assets** 下载 **city-texture-v0.4.0-offline.zip**，完整解压后双击 **打开城市纹理.html**。也可直接下载 **city-texture-v0.4.0.html**，用 Chrome / Edge 打开。

无需安装 Node.js、Python 或其他依赖，断网可用。ZIP 包内附中文使用说明、样本包格式、程序与地图许可及版本信息。

## 这次增加了什么

- “管理样本”面板：导入、下载和移除城区样本包，导入后加入左侧同尺度比较。
- 导入城市的道路与建筑参与联动探索、视图恢复、JSON 报告与 PNG 观察卡。
- 对重复 ID、损坏文件、超大文件、坐标、节点一致性、建筑闭环、下载范围与资源数量进行检查；错误输入保留当前比较。
- 地图、报告与观察卡标注导入数据来源；修正南半球和西半球的坐标显示。

## 导入前了解这几点

- 当前接受城市纹理样本包 v1，不直接接受统计报告、GeoJSON 或原始 Overpass 文件；可下载内置样本包查看格式。
- 每份最多 8 MiB，同时最多导入 3 份。刷新或关闭页面后需要重新导入；分享视图时请附带同一份样本包。
- 导入数据只在本地浏览器处理。来源、许可与原始数据校验值为提供者声明，应用不重新核验原始数据真实性或完整多边形拓扑。

仍内置苏黎世与伯尔尼两个局部样本，支持四种统一尺度、三种图层和真实建筑内院。局部样本不代表整座城市；建筑轮廓要素数不是实际楼栋或住房数。

## 验证与源码

41 项 JavaScript、9 项 Python 检查与四份原始地图快照的离线重建均通过。发布流程使用真实 Chrome 验证最终发行 HTML 的地图交互、文件导入与离线运行，然后下载所有上传附件，核对字节内容、版本、源码提交和 SHA-256，通过后再公开发行版。
