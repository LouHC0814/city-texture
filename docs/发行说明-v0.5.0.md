这一版加入南京新街口周边的真实道路和建筑样本，可与苏黎世、伯尔尼任取两城进行同尺度比较。

## 下载后怎么用

在下方 **Assets** 下载 **city-texture-v0.5.0-offline.zip**，完整解压后双击 **打开城市纹理.html**。也可直接下载 **city-texture-v0.5.0.html**，用 Chrome / Edge 打开。

无需安装 Node.js、Python 或其他依赖，断网可用。打开后在任一城市列表中选择“南京”。默认比较仍为苏黎世与伯尔尼，旧视图参数保持可用。

## 这次增加了什么

- 南京新街口约 1.1 km 下载范围：433 条受支持道路、350 个建筑轮廓要素，包含 7 个多边形关系和 5 个内环，没有建筑在转换时被跳过。
- 南京参与四种尺度、三种图层、联动平移、交换、视图恢复、JSON 报告、PNG 观察卡及样本包导出。
- 2026-10-17 分别取得道路和建筑原始响应，归档查询、抓取时间、快照标识与 SHA-256，可离线重建；内置样本扩为三个城区、六份原始归档。
- 发行版包含原始 Overpass 离线转换器的既有改进；开发者可在源码中将 JSON / JSON.gz 转成应用支持的样本包，普通使用不需要运行工具。

## 怎样理解南京样本

这是新街口周边的局部 OSM 快照，不代表南京全市。开启步行道路时会包含已标注的地下及室内通道，平面图没有区分层级；不应将所有线条理解为地面街道。界面、来源与导出保留统计口径说明。

建筑数字是当前窗口中的 OSM 轮廓要素数，不是实际独立楼栋或住房数。方向多样性不用于评价城市品质。样本包仍支持离线导入，每份最多 8 MiB，同时最多 3 份，刷新后需重新导入。

## 验证与源码

46 项 JavaScript、23 项 Python 检查及六份原始地图快照的离线重建；真实 Chrome 进一步检查南京的城市切换、尺度、图层、移动恢复、JSON / PNG、手机布局与断网显示。发布流程验证最终发行 HTML，再下载五份附件，逐字节核对版本、源码提交和 SHA-256，通过后公开。
