这一版支持保存完整比较项目：下次打开时，导入样本和观察位置一起恢复。

## 下载后怎么用

在下方 **Assets** 下载 **city-texture-v0.6.0-offline.zip**，完整解压后双击 **打开城市纹理.html**。也可直接下载 **city-texture-v0.6.0.html**，用 Chrome / Edge 打开。无需安装依赖，断网可用。

## 保存并接着看

1. 选好城市、尺度、图层和位置后，点“保存比较”，下载比较项目 JSON。
2. 下次打开程序，点“打开比较”，选择这个文件。
3. 查看预览后点“打开这份比较”，恢复两侧视图和全部导入样本。

文件最多 32 MiB，会携带选中的内置样本和全部最多三份导入样本，包括暂未显示的样本。打开会替换当前导入集合和比较位置；需要保留当前工作时可先保存。选择文件或取消面板不改变当前比较。

## 校验与兼容

- 所有样本、视图和计算缓存通过校验后才一起应用。损坏、超量、重复或缺失样本保留原比较。
- 同名内置样本必须与当前程序中的几何、说明和来源一致；不允许文件冒用内置 ID 改写快照。导入来源始终保留用户声明标注。
- 旧视图参数与单个样本包继续支持。比较项目用于整次观察，统计报告和单个样本包各有自己的打开入口。
- 手机布局、慢读取取消与断网单文件恢复均纳入真实 Chrome 检查。

本版仍内置南京、苏黎世和伯尔尼三个局部样本。地图未区分地下及室内层级，建筑要素数不是独立楼栋数，方向多样性不用于评判城市品质。

## 验证与源码

56 项 JavaScript、23 项 Python 检查和六份原始归档的离线重建；真实 Chrome 验证项目实际下载、重新打开、三份导入样本整体替换、预览取消、损坏与超大输入保护、手机和断网运行。发行流程还会实测最终 HTML，并回下载逐字节核对全部五份附件，通过后公开。
