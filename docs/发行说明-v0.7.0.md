城市纹理加入第一个真正可旋转观察的经典建筑三维模型：埃菲尔铁塔。

## 下载后体验

在下方 **Assets** 下载 **city-texture-v0.7.0-offline.zip**，完整解压后双击 **打开城市纹理.html**。也可直接下载 **city-texture-v0.7.0.html**，用新版 Chrome / Edge 打开。

点 **经典建筑 3D**，拖动模型旋转、滚轮或双指缩放；可切换正面、俯视和立体视角，也可自动旋转、查看线框、保存三维观察卡或下载 GLB。模型和引擎随文件保存，断网可用，无需账号或安装依赖。

## 这次完成了什么

- 接入 SDC 制作、CC BY 4.0 授权的完整埃菲尔铁塔模型，保留 147,604 个三角面与钢架细节，并记录原始文件及校验值。
- 本地打包 Three.js、OrbitControls 和 GLTFLoader，三维展台具备真实 WebGL 深度、光照与观察角度。
- 支持鼠标、键盘、单指旋转、双指缩放/平移；隐藏展台和切到后台时停止绘制。图形失败时可重试，城区比较继续可用。
- GLB 和观察卡保留原作者、原作链接、许可与修改说明。ZIP 和单文件都附所需许可。

现有南京、苏黎世和伯尔尼的双城比较、导入样本、项目保存和旧视图继续支持。

## 如实说明当前范围

这一版只有一份独立三维建筑模型。南京经典建筑精细模型尚未接入；目前的模型不是扫描或测绘成果，展示缩放后不能直接量取真实米数，也没有室内漫游。城区比较项目保存范围不包括三维相机。

61 项 JavaScript、23 项 Python 检查，六份 OSM 归档和三维模型/引擎离线重建；真实 Chrome 检查 WebGL 像素、相机变化、三种视角、鼠标/键盘/触摸、双指缩放、导出、图形故障恢复和断网模型。发布流程还会实测最终 HTML，再回下载逐字节核对五份附件后公开。
