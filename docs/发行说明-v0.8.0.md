# v0.8.0 · 保存建筑观察，继续离线探索

本版把独立三维视角保存与恢复加入正式离线包，并整理可复用的模型体检工具源码。

## 下载与使用

推荐下载 city-texture-v0.8.0-offline.zip，完整解压后打开“打开城市纹理.html”。也可直接下载 city-texture-v0.8.0.html，用新版 Chrome / Edge 打开；不需要安装 Node.js 或 Python，断网可用。

## 本版变化

- 经典建筑 3D 新增“保存三维视角／打开三维视角”：JSON 记录当前模型、相机、观察目标、投影、预设与线框，打开前先预览。文件最多 16 KiB，错误或取消保留当前观察。
- 恢复后可继续旋转、缩放及切换角度；手机与桌面视口切换、近景在地图与展台之间往返时保持恢复位置。
- 修复快速关闭并重开比较项目或视角预览时，延后的旧关闭事件清空新预览的问题。
- 修复浏览器自动检查中的下载事件订阅时序和文件识别问题，以真实文件和相机状态验证恢复。
- 新增 tools/模型体检：有限范围的静态自包含 GLB 检查器、中文报告、离线预览、反例及原始实验记录。它是开发辅助工具，普通应用使用者无需运行。基线从仓库已归档模型离线还原，不重复提交大文件。

## 验证

主应用 JavaScript、Python、六份原始地图快照和三维产物重建检查；真实 Chrome 软件 WebGL 检查最终发行 HTML、实际下载/打开、近远景、跨视口、触摸、错误文件保护及断网。

现有 npm test 与 npm run test:browser 同时执行应用与模型工具检查。模型工具单独检查准入、几何、引用、节点图、数值溢出、报告写入、依赖只读校验与真实预览。具体结果见对应源码提交的 Actions；发行文件上传草稿后重新下载并逐字节及 SHA-256 核对，通过后公开。

## 范围

三维展台仍为 SDC / CC BY 4.0 的埃菲尔铁塔，保留 147,604 个三角面，不宣称测绘精度或真实量尺。南京经典建筑模型尚未取得和接入。

三维视角文件与城区比较项目分开保存。模型工具版本与主应用独立；实验帧间隔不代表真实手机性能或 GPU 耗时。此版仍为离线程序，未部署在线站点。
