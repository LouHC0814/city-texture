# 城市纹理 v0.9.0 · 建筑模型工作台

现在可以把本地建筑 GLB 加入三维展台，切换观察，再把模型、资料与视角保存成完整工作台。

下载 city-texture-v0.9.0-offline.zip，解压后打开“打开城市纹理.html”；也可直接打开 city-texture-v0.9.0.html。无需安装依赖，断网可用。

## 本次新增

- 建筑收藏与本地 GLB 导入：最多三份，每份 8 MiB，总量 16 MiB，保留原始字节、SHA-256、来源声明和版权文字。
- 各建筑保留独立相机、目标、投影和线框；不同形状适配初始构图，切换暂停自动旋转并释放旧几何、材质、贴图。
- 保存／打开完整工作台：JSON 携带本地模型和各自视角，刷新或换设备后恢复，24 MiB 上限，先预览再确认替换。
- 模型下载与署名观察卡跟随当前建筑，旧铁塔视角继续兼容，本地视角以完整文件哈希绑定。
- 离线准备脚本有限范围合并 glTF ZIP，保留原件、来源和校验值，再运行既有体检。

## 错误保护与验证

共享准入拒绝外部资源、不支持的扩展、损坏引用和非有限世界范围；静态通过后还需实际解码图片。错误、取消慢读取、过期加载均保留原观察；快速切换只提交最后有效选择。

应用及工作台 JavaScript 单元检查 83 项、独立模型工具 507 项、Python 数据及接入检查 35 项。真实 Chrome 检查原有城区、项目恢复、三维交互及旧视角，并覆盖新工作台的 PNG/JPEG 实际贴图、下载、独立视角、真正刷新恢复、错误与取消、快速切换、资源释放、手机触摸和断网。

正式流程验证最终发行 HTML，再上传并回下载五份附件，逐字节与 SHA-256 核对后公开；具体结果以对应提交 Actions 为准。
