# 建筑模型工作台

v0.9.0 支持个人建筑收藏。内置模型仍为 SDC 的埃菲尔铁塔；南京紫峰原始模型尚未取得、未内置。

## 加入与切换

1. 打开程序，点“经典建筑 3D”，等待铁塔出现。
2. 点“加入模型”，选择自包含 GLB。程序先检查结构、引用、网格、图片声明及数值，再实际解码图片；文件不会上传。
3. 填写建筑名称、地点、作者、许可和原始来源。未知项可留空，程序会标明未声明，不把导入当作已经取得公开分发许可。
4. 点“加入并观察”，以后在“建筑收藏”中选择。不同模型保留独立相机、目标、投影与线框，切回时恢复；切换会暂停自动旋转。

最多三份本地模型，每份 8 MiB、合计 16 MiB，内置铁塔不占名额。每份模型最多 16 张图片，单张最多 4096 × 4096，合计最多 16 Mi 像素，防止压缩文件很小而解码占用过大。支持静态自包含 glTF 2.0 GLB、内嵌 PNG/JPEG；暂不支持 Draco、meshopt、量化、动画、骨骼及外部图片。限制比开发用体检 CLI 更小。错误文件、实际图片解码失败及取消操作保留当前模型、收藏和相机。

取得的是 glTF ZIP 时，可先用仓库 scripts/准备南京模型.py 离线合并，见《南京三维接入》。转换需要 Python 和 Node.js；直接运行应用或导入已有 GLB 不需要这些依赖。

## 保存整套收藏

点“保存工作台”，下载“城市纹理-建筑工作台.json”，其中包含所有本地模型的原始 GLB、来源声明、当前建筑与各建筑最近的视角。关闭、刷新或换设备后，先打开城市纹理，再点“打开工作台”，预览后确认“打开并替换工作台”。确认会替换页面收藏，内置铁塔保留。

工作台最多 24 MiB。损坏文件、校验值错误、缺失模型、错误视角及关闭慢读取都不会覆盖现有观察。当前没有浏览器后台持久化，刷新前必须主动保存；工作台携带完整模型，分享时应按实际模型许可处理。

## 单独视角、导出与移除

“保存三维视角”仍为最多 16 KiB 的独立 JSON，只对应同一模型。旧铁塔视角兼容；本地模型以原始文件 SHA-256 绑定，同一文件重新导入后可恢复其视角，其他模型的视角会拒绝。

“下载模型 GLB”返回当前模型原始字节；“保存三维观察卡”导出 1600 × 1200 PNG，标题、作者、许可和来源随当前模型更新，原文件内版权文字另行保留。导入资料属于提供者声明，程序不鉴定建筑身份、测绘精度或授权真实性；显示缩放不用于测量。

“移除当前模型”先切回铁塔，再移除该模型与页面视角，不改变磁盘原件。另存新工作台后才把移除结果写入文件；以前的工作台仍保留旧收藏。

| 保存按钮 | 内容 | 携带三维模型 |
| --- | --- | --- |
| 保存比较 | 二维城区样本和比较设置 | 否 |
| 保存三维视角 | 当前建筑相机、目标与线框 | 否 |
| 保存工作台 | 建筑收藏、来源与各自视角 | 是；内置铁塔由程序提供 |
