# 建筑工作台格式 v1

UTF-8 JSON，与二维比较项目、三维视角和模型体检报告不同。

| 字段 | 含义 |
| --- | --- |
| format / version | city-texture-model-workspace / 1；拒绝未知版本和未知顶层字段 |
| activeId | eiffel-tower 或文件中存在的本地模型 ID |
| models | 最多三项，每项含 id、metadata、data |
| models[].id | local- 加原始 GLB 完整 SHA-256，不按名称识别 |
| models[].metadata | name、place、author、license、source、note；来源限不含账号信息的 HTTPS |
| models[].data | 规范 base64 GLB，每份解码后最多 8 MiB，合计 16 MiB |
| views | 模型 ID 到三维视角 v1 的映射，键与 modelId 必须一致 |

文件最多 24 MiB。内置铁塔不重复携带文件，旧 eiffel-tower ID 保持稳定。导入模型重新计算 SHA-256 并运行共享静态准入；哈希不用于鉴定建筑身份或授权真实性。

预览只构造候选集合，不修改模型注册表。确认后先实际加载所选模型并核对其视角与裁剪范围，成功才替换收藏和场景；切换其他模型时继续检查。取消读取、过期请求和加载失败保留旧集合。

保存原始 GLB 和资料，不保存 GPU 对象、Blob 地址、浏览器路径或自动旋转进度。版权文字仍由原始 GLB 保留，不用可编辑 metadata 替代。
