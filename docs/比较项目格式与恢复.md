# 比较项目：保存后接着观察

v0.6 起，点“保存比较”会下载 `城市纹理-比较项目.json`。文件同时保存当前左右城市、观察尺度、道路筛选、图层、移动位置，以及当前全部导入样本。下次打开程序后点“打开比较”，选择文件，检查预览，再点“打开这份比较”。断网也能恢复。

选择文件和关闭面板都不会改变当前比较。点击“打开这份比较”后，文件中的导入集合会整体替换当前导入集合，随后恢复观察位置；内置样本始终保留。需要保留当前工作时，先关闭面板并保存当前比较。

## 保存了什么

- 当前选中的内置样本，最多两份，携带完整道路、建筑、下载框和来源。
- 当前全部导入样本，最多三份，包括未在两侧显示的样本。
- 当前视图片段，保留毫米精度的相对位置。单份样本只保存一次，两侧可以选择同一份。

未选中的内置样本不重复放入文件。项目不保存 PNG、计算缓存、浏览器路径或远程凭据，也不会上传数据。文件中的来源地址只作文字保存，打开项目不会访问这些地址。

## 文件格式

项目是 UTF-8 JSON（可带 BOM），最多 32 MiB，格式如下。示例仅展示结构，`samples` 需要放入完整的[样本包 v1](样本包格式与导入.md)。

```json
{
  "format": "city-texture-project",
  "version": 1,
  "view": "#v=3&a=nanjing&b=zurich&s=0.5&w=1&l=both&x=20.000&y=-10.000",
  "samples": []
}
```

| 字段 | 约束 |
| --- | --- |
| `format / version` | 固定 `city-texture-project` / `1` |
| `view` | 有效城市纹理视图参数；左右样本必须实际包含在此文件中。v1/v2 旧视图可读取并转为规范 v3 |
| `samples` | 1–5 份完整样本包，ID 不重复；最多三份视作导入样本，每份仍受 8 MiB 和原有资源上限约束 |

打开前完整校验所有样本及几何缓存。错误输入、缺失样本、重复 ID、数量超限、损坏建筑和超大文件都不改变当前比较。越界的位置会按道路与建筑的共同下载范围向内约束。

## 数据身份与版本兼容

同名内置 ID 必须与程序中的样本完全一致：规范化后的几何、中心、下载框、说明和来源全部比较，不能仅靠文件自称“可信”或填写相同原始哈希来覆盖内置快照。不一致时停止打开，请使用保存时对应的程序版本，或为修改过的数据生成独立 ID 的样本包。

文件包含程序不认识的 ID 时，按导入样本校验和标注，仍计入最多三份的上限。导入来源始终标注为用户声明，程序不会重新下载原始数据核验，也不把样本包格式校验等同于地图真实性或完整 GIS 拓扑验证。

比较项目、单个样本包和统计报告是不同文件：项目用于接续整次观察，样本包用于单独增添城区，报告用于阅读统计。地图数据 © OpenStreetMap contributors / ODbL 1.0；分享项目时应保留其中的来源与许可。
