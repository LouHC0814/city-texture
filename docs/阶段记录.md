# 阶段记录

## v0.7.0 · 经典建筑三维展台

2026 年 10 月 17 日：用户明确希望从多个角度观看经典建筑的完整三维模型。开发重点转向独立建筑展台，先在 GitHub 查验 Three.js、世界建筑示意模型及 SDC 埃菲尔铁塔资源。

- 接入有钢架细节的 SDC / CC BY 4.0 埃菲尔铁塔模型，完整保留 147,604 个三角面；归档原始 glTF、二进制和作者许可，校验后转换为自包含 GLB。
- 本地打包 Three.js r186、OrbitControls、GLTFLoader、RoomEnvironment；发行 HTML 内含模型和引擎，无在线/CDN 依赖。
- 支持旋转、缩放、平移、三种预设视角、键盘、手机单指/双指、自动旋转、线框、署名观察卡与 GLB 下载；隐藏与后台停止绘制，图形异常可重试。
- 61 项 JavaScript、23 项 Python 检查；真实 Chrome 的软件 WebGL 检查真实像素、相机与视角变化、触摸、导出、故障恢复和断网单文件。模型与引擎重建需逐字节一致。
- 这是第一份独立三维模型，南京精细模型尚未接入，不宣称扫描精度或真实测量尺度。比较项目仍保存城区比较，不保存三维相机。

参见 [v0.7.0 发行说明](发行说明-v0.7.0.md)。

## v0.6.0 · 保存和打开完整比较项目

2026 年 10 月 17 日：在 GitHub 检查 Excalidraw 的状态与素材序列化、geojson.io 的文件打开流程后，实现原生本地比较项目文件。

- 一个 JSON 保存当前视图、选中的内置样本与全部最多三份导入样本；刷新后或换设备时可直接打开继续观察。
- 选择文件只预览；确认打开后一次替换导入集合与视图，内置样本保留。错误文件和取消操作不改变当前比较。
- 项目最多 32 MiB，单样本仍为 8 MiB；全部样本、视图和计算缓存预先校验。同名内置样本需几何、说明与来源一致，避免冒充内置快照。
- 56 项 JavaScript 与 23 项 Python 检查；真实 Chrome 覆盖实际下载/重新打开、三份导入整体替换、预览取消、慢读取取消、坏文件保护、手机与断网恢复。
- 发行包附比较项目格式说明；既有三城数据和六份可复核归档保持原样，旧视图与样本包兼容。

参见 [v0.6.0 发行说明](发行说明-v0.6.0.md)。

## v0.5.0 · 南京新街口真实样本

2026 年 10 月 17 日：先在 GitHub 检查 city-roads、OSMnx 与 overpass-turbo 的相关做法，加入南京新街口周边道路与建筑。项目约定将开发前检索参考和记录出处作为后续流程。

- 使用 WGS84 中心与真实公共 Overpass 响应：433 条受支持道路、350 个建筑轮廓要素、7 个多边形关系、5 个内环，无建筑跳过。
- 内置三座城区可任取两座；原苏黎世/伯尔尼默认和旧视图兼容。南京加入尺度、图层、平移、恢复、JSON / PNG 及离线样本包。
- 标明地下/室内通道的二维统计口径；可选样本说明保留在地图与报告，来源中的限制也随样本包保存。
- 六份原始归档按来源哈希校验并离线重建；打包脚本从入口发现全部本地脚本，避免新增城市漏入单文件。
- 46 项 JavaScript 与 23 项 Python 检查；真实 Chrome 覆盖南京的三种图层、四种尺度、移动恢复、导出、手机与断网单文件。发行流水线核验最终 HTML 与五份回下载附件后公开版本。

参见 [v0.5.0 发行说明](发行说明-v0.5.0.md)。以下条目保留各历史阶段当时的状态。

## v0.4 后续开发 · 原始 Overpass 离线转换

2026 年 10 月 17 日：新增通用的本地 JSON / JSON.gz 转换器。已发布的 v0.4.0 应用可以直接导入其产物；这次仅更新源码中的开发工具，没有更改已发布附件。

- 通过配置指定城市、两份原始文件、下载框和来源，计算解压后原始响应的 SHA-256；有预期哈希或快照标识时强制核对。
- 复用既有建筑拼接与内院处理，最终使用应用同一份 Node 校验器；错误和损坏建筑默认停止，显式允许跳过时保留原因。
- 保留原始输入，默认不覆盖输出；校验成功才原子写入。不会自动联网或用文件修改时间推算抓取时间。
- 提供既有苏黎世快照的可运行演示，不声称新增城市；23 项 Python 检查涵盖两座真实城区及错误保护，CI 实际导入转换器生成的文件。

详见 [Overpass 离线转换](Overpass离线转换.md)。应用内置样本仍为苏黎世、伯尔尼。

## v0.4.0 · 离线样本包

2026 年 10 月 17 日：从 v0.3.0 继续，新增项目格式的离线样本包导入、下载与移除。

- 样本包同时保存道路、建筑与各自来源，可与内置样本同尺度比较；单包不超过 8 MiB，同时最多 3 份。刷新或关闭后需重新导入。
- 解析 JSON 后只重建允许字段，检查来源声明、经纬度、节点一致性、建筑闭环、非零环面积与共同下载框。错误、重复 ID、超量输入保留现有比较。没有执行输入脚本或上传文件。
- 地图、JSON 和 PNG 标注用户导入来源；应用不核验提供者的原始哈希或地图真实性。修正南/西半球经纬度显示，适用于新增地区。
- 复制视图沿用 v3；遇到未加载的样本，手动恢复提示先导入同一份样本包。
- JavaScript 共 41 项检查，Python 仍为 9 项；CI 新增实际 Chrome 文件导入、再导出、视图恢复、错误保护、手机面板及断网单文件检查。以分支 Actions 的结果为准。

内置城市仍为苏黎世、伯尔尼；原始 Overpass / GeoJSON 直接导入、全球搜索和在线部署仍待后续。发行流程会在最终 HTML 浏览器检查和五份附件回下载逐字节核对通过后发布 v0.4.0；ZIP 中包含样本包格式说明。

## v0.3.0 · 建筑轮廓与街区观察

2026 年 10 月 16 日：加入苏黎世、伯尔尼两份真实 OSM 建筑快照。

- 收录 1,573 / 1,359 个建筑轮廓要素，支持闭合 way、乱序/反向成员的 multipolygon 拼接和内院保留。
- 道路、叠加、建筑三种图层；建筑要素数随窗口移动、缩放与城市选择变化。
- 以正面积交集判断计数，内院中的窗口和仅触边轮廓不误计；不输出覆盖率或实际楼栋数。
- v3 视图参数保留图层，旧 v1/v2 保持仅道路。JSON / PNG 分别记录道路和建筑的抓取来源。
- 四份原始归档离线重建一致；32 项 JavaScript 检查与 9 项 Python 检查通过。真实浏览器检查三种画布、真实内院像素、联动统计、导出与离线单文件。

仍使用两个城区样本，没有在线部署。

## v0.2.0 · 连动探索与可恢复视图

在真实城区路网比较的基础上，加入可移动的观察窗口。

- 鼠标拖动左右任一地图或手机触摸拖动，两侧地图保持相同的东/北公里位移。
- 方向按钮和键盘方向键逐步移动；Home 和“居中”恢复位置。
- 取两份下载框的共同有效范围，限制移动与缩放后的窗口位置，显示边界提示。
- 当前坐标、道路指标、方向分布、PNG 和 JSON 导出全部随位置更新。
- 复制/恢复包含位置的 v2 视图参数，兼容 v1 参数；自动复制不可用时显示手动复制框。
- 错误恢复输入保留原有比较；本地预览不伪装成公开链接。
- 23 项几何、数据与视图检查通过。真实 Chrome 验证鼠标/触摸/键盘、边界、导出、恢复及离线运行；剪贴板接口仅在隔离测试中模拟成功和失败，不宣称已在所有系统上验证真实剪贴板。

样本仍是苏黎世、伯尔尼的小范围 OSM 道路快照。没有新增城市、建筑图层或在线部署。
