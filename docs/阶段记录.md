# 阶段记录

## v0.4.0 · 离线样本包（开发预览）

2026 年 10 月 17 日：从 v0.3.0 继续，新增项目格式的离线样本包导入、下载与移除。

- 样本包同时保存道路、建筑与各自来源，可与内置样本同尺度比较；单包不超过 8 MiB，同时最多 3 份。刷新或关闭后需重新导入。
- 解析 JSON 后只重建允许字段，检查来源声明、经纬度、节点一致性、建筑闭环、非零环面积与共同下载框。错误、重复 ID、超量输入保留现有比较。没有执行输入脚本或上传文件。
- 地图、JSON 和 PNG 标注用户导入来源；应用不核验提供者的原始哈希或地图真实性。修正南/西半球经纬度显示，适用于新增地区。
- 复制视图沿用 v3；遇到未加载的样本，手动恢复提示先导入同一份样本包。
- JavaScript 共 41 项检查，Python 仍为 9 项；CI 新增实际 Chrome 文件导入、再导出、视图恢复、错误保护、手机面板及断网单文件检查。以分支 Actions 的结果为准。

内置城市仍为苏黎世、伯尔尼；原始 Overpass / GeoJSON 直接导入、全球搜索和在线部署仍待后续。v0.4 尚未发布 Release。

## v0.3.0 · 建筑轮廓与街区观察

2026 年 10 月 16 日：加入苏黎世、伯尔尼两份真实 OSM 建筑快照。

- 收录 1,573 / 1,359 个建筑轮廓要素，支持闭合 way、乱序/反向成员的 multipolygon 拼接和内院保留。
- 道路、叠加、建筑三种图层；建筑要素数随窗口移动、缩放与城市选择变化。
- 以正面积交集判断计数，内院中的窗口和仅触边轮廓不误计；不输出覆盖率或实际楼栋数。
- v3 视图参数保留图层，旧 v1/v2 保持仅道路。JSON / PNG 分别记录道路和建筑的抓取来源。
- 四份原始归档离线重建一致；32 项 JavaScript 检查与 9 项 Python 检查通过。真实浏览器检查三种画布、真实内院像素、联动统计、导出与离线单文件。

仍使用两个城区样本，没有在线部署。

## v0.2.0 · 连动探索与可恢复视图

在真实城区路网比较的基础上，加入可移动的观察窗口。

- 鼠标拖动左右任一地图或手机触摸拖动，两侧地图保持相同的东/北公里位移。
- 方向按钮和键盘方向键逐步移动；Home 和“居中”恢复位置。
- 取两份下载框的共同有效范围，限制移动与缩放后的窗口位置，显示边界提示。
- 当前坐标、道路指标、方向分布、PNG 和 JSON 导出全部随位置更新。
- 复制/恢复包含位置的 v2 视图参数，兼容 v1 参数；自动复制不可用时显示手动复制框。
- 错误恢复输入保留原有比较；本地预览不伪装成公开链接。
- 23 项几何、数据与视图检查通过。真实 Chrome 验证鼠标/触摸/键盘、边界、导出、恢复及离线运行；剪贴板接口仅在隔离测试中模拟成功和失败，不宣称已在所有系统上验证真实剪贴板。

样本仍是苏黎世、伯尔尼的小范围 OSM 道路快照。没有新增城市、建筑图层或在线部署。

## v0.1.0 · 同尺度双城观察

- 独立实现 Canvas 绘图、局部公里投影、线段裁剪、节点对去重、密度与方向分析。
- 支持四种观察尺度、道路筛选、城市交换、PNG / JSON 导出和离线单文件。
- 归档原始 OSM 数据与 SHA-256，支持逐字节离线重建。
- 17 项几何与数据检查，以及真实浏览器验证通过。
