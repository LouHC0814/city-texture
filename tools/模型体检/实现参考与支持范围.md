本轮的实际任务不是把一个 GLB 接入主项目，而是先做出一套可以重复运行的**离线三维模型体检工具 + 独立预览实验**，把任何候选资源跑出机器可读、人类可读、真实可看三份结果。本文档记录已阅读的官方实现、采用的参考点、采用方式、首版支持范围与明确标注为“不支持/待评估”的边界。

## 3 自己的实现重点

任务书 §3 指出工具核心不是“又写一个 glTF 解析器”，而是把以下几件事做对：

1. **统计口径**——区分几何三角形 / 实例三角形 / POSITION 记录数；按 primitive.mode 计数；把自报 min/max 与实算分开。
2. **离线边界**——拒绝任何带 http(s)/file/相对路径的 buffer 或图片引用；首版不联网。
3. **中文报告**——不依赖 CDN、能在 file:// 打开的 HTML；含可读中文问题说明。
4. **实验与回归**——程序化生成可解释的小 GLB 作为反例，验证包围盒、实例数、损坏检测、外部资源、未声明扩展等口径。
5. **稳定可重复**——同输入同配置输出可重复；时间、机器信息放在运行元数据中，与稳定指标分文件。

## 4 首版支持范围

> 满足任务书 §3“首版必须支持”清单，并逐条落地到实现。

- **GLB 2.0 容器**：magic = `glTF`、version = 2、JSON chunk + 单一 BIN chunk（不做多 BIN 或 外部 BIN 的拼接）。
- **自包含**：任何 buffer / image 引用了非嵌入 URI（http/https/file/相对路径）→ `E_NOT_SELF_CONTAINED`，**判 error、不允许进入预览**。`buffer` 用 `data:` 也判 `E_BUFFER_DATA_URI_UNSUPPORTED`（无法核验容量）。首版不联网取回。
- **静态建筑网格**：mesh / primitive / node 树为静态，无动画、无 morph、无 skin。
- **未压缩 POSITION / indices**：POSITION 必须是 float32 VEC3（量化/整型一律 unsupported）。indices 允许 5121 / 5123 / 5125。
- **节点图**：每个节点最多一个父（多父判 `E_NODE_MULTI_PARENT`）；环与超深（>32）在**全部场景与未挂接节点**上检查，不只默认场景。
- **常用节点变换**：matrix（4×4）与 TRS（translation/rotation/scale）均支持；父子级联后世界矩阵必须逐元素有限。
- **嵌入图片**：mime 仅 `image/png` 与 `image/jpeg`；取 bufferView 字节数与（纯 JS）解析 PNG IHDR / JPEG SOF 段得到宽高；不渲染，仅做尺寸校验。

**几何三角形数**：

- primitive.mode = 0（POINTS）：忽略；
- mode = 1（LINES）：不计入三角形数；如需长度，按 indices.count/2；
- mode = 2（LINE_LOOP）：不计入；
- mode = 3（LINE_STRIP）：不计入；
- mode = 4（TRIANGLES）：`floor(indices.count / 3)`，无 indices 时按 POSITION.count/3；
- mode = 5（TRIANGLE_STRIP）：`(indices.count - 2)`；
- mode = 6（TRIANGLE_FAN）：`(indices.count - 2)`，并提示退化三角形风险；
- 未知 mode：标 `W_UNKNOWN_PRIMITIVE_MODE`，不参与求和。

`几何三角形` = Σ 上述方式逐 primitive 的结果（独立 mesh 自身）；`场景实例三角形` = Σ 场景中节点引用 mesh 的次数 × 该 mesh 几何三角形，节点不被引用时也算 0 实例。`POSITION 记录数` = Σ POSITION accessor.count，不跨 mesh 去重（避免假精度）。

**包围盒**：对每个被默认场景引用的节点，把其 POSITION accessor 的全部顶点逐个变换到世界坐标后取 min/max（不是 8 角点）。**不**相信 `accessor.min`/`accessor.max`；同时报告自报值与实算值，差异作为 `W_BBOX_MISMATCH` 提醒。8 角点版本单独叫 `bounds.conservative`，只用于快速剔除。

包围盒由共享准入在数据段计算：只要任一中间/最终结果非有限，就判 `E_WORLD_MATRIX_NON_FINITE` / `E_WORLD_POSITION_NON_FINITE` / `E_WORLD_BOUNDS_NON_FINITE`，**不存在"准入 pass 但包围盒为 null"的状态**。

**默认场景**：取 `scene` 字段指定的场景；缺省取 `scenes[0]`。未引用的 mesh 在"统计"里仍出现，但实例数计 0。

## 5 明确不支持 / 待评估

> 任何命中此清单的输入都会报告问题代码 + 中文说明，**不**给出虚假的“全部兼容”结论。

- 稀疏 accessor、`EXT_meshopt_compression`、`KHR_mesh_quantization`、Draco / Basis 压缩：报告 `E_UNSUPPORTED_EXTENSION` / `E_UNSUPPORTED_FEATURE`，不读相关 accessor。
- 骨骼 / 蒙皮 / 变形目标（`skins` / `morphTargets`）：报告 `E_UNSUPPORTED_FEATURE`。
- 动画（`animations`）：同上报错。
- 外部 buffer / 外部图片（任何非 `data:` 引用）：报告 `E_NOT_SELF_CONTAINED`，判 error，不自动取回。
- `KHR_materials_unlit` 等超出基线材质的扩展：报告 `E_UNSUPPORTED_EXTENSION`。
- 嵌入 VORBIS / OGG 音频：不读取，仅在 `extensionsRequired` 命中时报 `E_UNSUPPORTED_EXTENSION`。
- 容量与防护：文件 > 64 MiB 拒绝；JSON chunk > 8 MiB 拒绝；节点深度 > 32 拒绝；accessor 元素总数 > 2²⁴ 拒绝。
- **数据级硬错误**（不是警告）：POSITION 含 NaN/Infinity、索引越界、世界变换溢出、bufferView 越过逻辑 buffer、材质 textureInfo 索引越界 —— 全部判 error 并停止出数。
- 显存、实际渲染开销、构建精度：均按任务书 §4 要求，**不**凭面数与体积折算"真实性/精度分数"。

## 6 计划交付的稳定字段

体检 JSON 报告采用如下稳定结构（格式标识 + 版本，便于后续程序读取）：

```jsonc
{
  "format": "city-texture-gltf-inspection",
  "formatVersion": 5,
  "run": { "tool": "city-texture.gltf-inspect", "toolVersion": "0.5.0", "startedAt": "...", "durationMs": ... },
  "input": { "name": "eiffel.glb", "bytes": 5696248, "sha256": "...", "detectedFormat": "glb-2.0" },
  "status": "pass", "fatal": false,
  "container": { "magicOk": true, "version": 2, "jsonChunkBytes": ..., "binChunkBytes": ..., "externalReferences": [] },
  "structure": { "buffers": 1, "bufferViews": ..., "accessors": ..., "meshes": ..., "primitives": ..., "nodes": ..., "scenes": ..., "nodesInDefaultScene": ... },
  "geometry": { "positionRecords": ..., "uniqueGeometries": ..., "geometryTriangles": ..., "sceneInstancesTriangles": ..., "byMode": { "TRIANGLES": ... }, "unknown": false },
  "materials": { "count": ..., "byType": { "PBR": ... } },
  "images": { "count": ..., "uniqueImageCount": ..., "byMime": { "image/png": ... } },
  "extensions": { "used": [], "required": [] },
  "bounds": {
    "computed":     { "min": [...], "max": [...], "center": [...], "size": [...] },
    "conservative": { "min": [...], "max": [...], "center": [...], "size": [...] },
    "selfReported": { ... }
  },
  "source": { "title": "...", "author": "...", "license": "CC-BY-4.0", "sourceUrl": "...", "notes": "..." },
  "issues": [
    { "code": "W_BBOX_MISMATCH", "severity": "warning", "message": "自报 min/max 与实算不一致", "target": "mesh/0" }

```

中文 HTML 报告不依赖 CDN；它把 JSON 渲染为人类可读的分块、问题汇总与可下载附件链接，方便人工复核。
